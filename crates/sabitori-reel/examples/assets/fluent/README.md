# 作例の絵の素材

ここの SVG は Microsoft の [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) の
Flat 版 (MIT ライセンス、同じフォルダの `LICENSE`)。架空業者シリーズの作例
(`bakery` / `night_radio` / `old_books` / `game_studio` / `architects` / `weather`) が
`include_str!` で読み、`sabitori_core::svg::Svg` で要素にして動かしている。

使っていない素材は置かない。
